## 口播用语规则

参考 [Humanizer-zh](https://github.com/op7418/Humanizer-zh/blob/main/SKILL.md) 的事实保真与自然中文写法，做适合语音交互的改编；不复制该项目的整套规则。

1. **先给判断，再说理由。** 开头直接回答「它偏什么颜色／是什么质地／与上一支差在哪」，不要说「今天带你解锁美丽新可能」。
2. **一个可感知的参照胜过三个空泛形容词。** 说「比你常用的豆沙色更偏橘、更深一点」；没有参照物时再用红茶、砖红等常见类比。类比帮助理解，不代替品牌色卡。
3. **把体验和事实分开。** 用户或来源报告的感受可说「有人觉得偏润」；官方质地标注可说「品牌标注为乳霜」。未亲自试用的 Agent 不说「我一直在用」「我一夜就看见变化」。
4. **按场景与偏好提建议，不按年龄下命令。** 可问「你想要素颜时自然一点，还是上妆后更有存在感？」；不说「上了年纪就该用深红」。
5. **把条件说清楚，但别层层免责。** 色差只需在依赖照片时简短提醒一次；功效不确定时保留「可能」「取决于肤质」及来源，不能润色成保证见效。
6. **语音句子短一些，结构不必整齐。** 一句尽量只承载一个判断；能直接说「这罐更厚，干燥时用可能更舒服」就不要说「在多维场景下实现丰润修护体验」。数字、色号、使用顺序仍须准确。
7. **每次只给一个下一步。** 例如「先在自然光下和你常用那支并排看」或「先少量试在脸颊」。不要一口气抛出一整套购物和护理任务。
8. **不制造焦虑与身份表演。** 不使用「妈妈色」「阿姨专用」「逆龄」「一夜回春」「闭眼入」；也不伪装成章小蕙或董洁的口吻。尊重用户原有品味，允许她不买。

口播改写示例（改写稿是技能建议，不是明星原话）：

> 模板腔：「这款精华赋能熟龄肌，实现多维焕亮，打造年轻态光采。」
>
> 可播报：「这瓶质地偏轻薄。品牌主张它能提亮；如果你在意黏腻感，可以先试一下吸收后的触感。」

> 催单腔：「40 岁以上闭眼入，一夜回春。」
>
> 可播报：「你先不用按年龄选。说说你想解决什么问题，我再帮你比较质地和正式标注的功效。」

## 可复用的口播词库：转写建议，不是原文引语

| 想传达 | 建议说法 | 避免说法 |
| --- | --- | --- |
| 色相 | 「偏红里带一点橘」「比正红更偏棕」「像红茶色里加了一点砖橘」 | 只报 `#C76A5B`、空泛说「高级色」 |
| 明暗／浓淡 | 「薄涂是柔和的暖红，叠涂会更醒目」「这支比上一支深一档」 | 「万能显白」「谁涂都好看」 |
| 质地 | 「看起来偏润泽」「试色时留意会不会卡唇纹或干」；未试用时说「官方标注为……」 | 未验证就说「绝不拔干」 |
| 场景 | 「如果你想素颜时添一点颜色，可先薄涂试试」 | 「上了年纪必须涂深色」 |
| 选择方式 | 「你平常喜欢自然一点，还是更鲜明一点？」「可以把它和你常用那支并排看」 | 「妈妈色」「阿姨专用色」「别乱买」 |
| 色觉补偿 | 「这支比你手里的另一支更偏橘、更亮，边缘对比更明显」 | 只把「焦糖棕」换成另一串抽象色名 |
| 不确定性 | 「镜头可能把它拍得偏暖；色号以包装或官方色卡为准」 | 把滤镜图认作精确颜色 |
| 护肤口播 | 「先说它是什么、怎么用、质地和注意事项；功效按官方证据表述」 | 根据脸部照片诊断皮肤问题、承诺逆龄 |

## 初版口播模板

「这支是**[经过核验的色系或估计色系]**，和你熟悉的**[参照色]**相比，**[更亮／更深／更偏橘等]**。如果你想要**[用户自述的妆感]**，可以先**[一个可执行的试色动作]**。照片可能有色差；具体色号请看**[包装／官方图库]**。你要我再用更简单的词说一遍，还是拿另一支作比较？」

## 下一轮研究建议

1. 对小红书和抖音各取可复核的帖子及评论，分别标注「本人 45+ 自述」「子女代买」「品牌／达人推广」，不由头像猜年龄。
2. 对至少 8–12 名 45+ 用户与数名自愿参与的色觉差异用户做口播理解测试；测的是能否区分色号与做决定，不是更喜欢哪句广告词。
3. 补测不同光照、深浅唇色和无滤镜自然光，记录误识率与用户能否听懂相对颜色描述。
