# 可视化契约

系统只从以下固定区域中选择一个：`full_face`（全脸常见涂抹范围示意）、`under_eye`（卧蚕/眼周）、`forehead`、`cheek`、`nose`、`chin`、`t_zone`（额头与鼻部的常见出油示意）、`nasolabial_fold`（法令纹）、`flaky_area`（局部起皮示例）。模型不能输出 SVG、HTML、图片地址或任意坐标。客户端使用内置原创、具象的正面面部示意图，根据区域编号动态高亮，并同时显示等价的文字说明；动画应尊重“减少动态效果”系统设置，提供暂停按钮。

只有用户明确询问面霜/乳液如何涂到全脸，才使用 `full_face`。该图是一般位置示意，不代表某个具体产品获准用于全脸；产品范围必须以已审核标签或来源资料为准。每轮优先按当前问题选图，不得仅因历史上聊过某部位就重复显示旧图；只有“这里/那个部位/刚才说的位置”等明确指代才可沿用上一轮的区域。

`under_eye` 分成两层语义：紧贴下睫毛的亮色位置是“卧蚕在哪里”；较低的虚线提示是“眼周产品可能的外围涂抹参照”。不能把二者合并为按摩路线。具体产品若未审核眼周用途，不应声称能涂在眼周。

图像不使用用户自拍，不推断年龄、健康、肤色或身份。它也不展示真实人的面部照片，因此无需上传人脸数据。带不适或医学问题的请求由原有风险/人工流程处理，不生成此图。

`t_zone` 只能表示日常所说的 T 区，不能据此断言用户为油性皮肤。`flaky_area` 的鼻翼旁与下巴只是帮助理解术语的示例，不能当作个体诊断。`nasolabial_fold` 仅定位纹路，不能暗示按摩或产品一定会消除它。
