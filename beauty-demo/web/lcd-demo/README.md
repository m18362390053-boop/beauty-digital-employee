# LCD 画面与交互模拟器

在 `beauty-demo/` 启动服务后访问 `http://127.0.0.1:3090/lcd-demo/`；也可以直接在浏览器打开本目录的 `index.html`。画面按 240×284 像素排版。

主页包含包装识图、说句话、护肤日程、悦见时刻。包装识图按“同意本次拍摄 → 单独同意本次外发 → 显示候选 → 咨询示例”演示；语音输入按“同意本次录音 → 单独同意本次外发 → 显示转写 → 咨询示例”演示，**识别/转写结果不再设置二次核对按钮**。步骤、区域高亮、模拟朗读状态和完成画面也可预览。转写出的护理口令不会执行护理动作。

**这是独立的静态展示页，不连接 USB、摄像头、麦克风、真实模型或护理数据库。**所有商品、候选、文字、次数和时间都是演示数据；点击“好了”不会产生真实完成记录，也不代表设备固件已经实现了这些功能。请勿把模拟结果作为实物验收证据。
