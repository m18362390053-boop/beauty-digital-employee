服务进程的环境变量（仅在后端配置；不要提交到仓库或贴进聊天）：

| 用途 | 环境变量 | 说明 |
| --- | --- | --- |
| 包装图片理解 | `VOLC_ARK_API_KEY` + `VOLC_VISION_MODEL` | 方舟模型 ID，须有图片输入能力；有值后优先于现有 DeepSeek Flash 图片入口。 |
| 短句音频转写 | `VOLC_ARK_API_KEY` + `VOLC_ASR_MODEL` | 方舟**音频理解**模型 ID，须支持 Responses API 音频输入；不等于豆包语音产品的专用 ASR 模型/资源 ID。 |
| 朗读 | `VOLC_VOICE_API_KEY` + `VOLC_TTS_SPEAKER` | 豆包语音控制台 API Key 与已开通的 2.0 音色 ID；固定使用 `seed-tts-2.0`。 |

确认曾暴露的密钥已撤销后，在启动后端的私有环境中配置新的 `VOLC_ARK_API_KEY`，或设置 `VOLC_ARK_API_KEY_FILE` 为更新后本地密钥文件的**绝对路径**；不再自动加载上级目录的 `doubao_api.txt`。文件请保存在 Git 忽略路径，不复制进数据库、网页、`.env` 或日志。有环境变量密钥时优先使用变量；文件格式不符合预期时禁用火山能力，日志只报通用错误。视觉模型设 `VOLC_VISION_MODEL=doubao-seed-2-0-mini-260428`；**音频理解是否支持及模型 ID 尚未验证**，不要自动把视觉模型 ID 用作 ASR。页面在用户主动授权外发时才发送媒体，启动或基础测试本身不调用付费模型。**方舟密钥不可代替 `VOLC_VOICE_API_KEY` 或 TTS 音色。**

Windows PowerShell 启动示例（在 `beauty-demo/` 执行，仅在确认文件中已是新密钥后使用）：

```powershell
$env:VOLC_ARK_API_KEY_FILE = 'C:\private\rotated-ark-key.txt'
$env:VOLC_VISION_MODEL = 'doubao-seed-2-0-mini-260428'

```

命令不包含密钥内容；如设置过旧的 `VOLC_ARK_API_KEY` 环境变量，先从启动终端删除该变量，避免覆盖文件。网页能力状态仍只是 `configured_unverified`，而非 SKU 图片验收。

路径固定指向官方域名；不接受用户自定义上传目标。密钥不返回网页，照片/录音不落后端文件或数据库；图片可视情况回退现有 DeepSeek Flash 入口（网页会显示本次外发服务商）。**不要把现有 `CHAT_API_KEY` 当火山 Key。**更改文件/变量后重启服务，通过 `GET /api/customer/input/capabilities` 核对状态。

- 图片：`POST /api/customer/packaging/recognize`，沿用单张照片授权、格式和候选确认接口；只有用户本人点击候选才能绑定咨询商品，不自动确认 SKU/护理步骤。若要**只允许火山**，不要配置 DeepSeek Flash 图片凭据；当前兼容旧入口以免破坏已有组员测试。
- ASR：页面点击录音，浏览器取得麦克风权限，最多录 20 秒，在浏览器转成单声道 16 kHz WAV；`POST /api/customer/speech/transcribe` 需登录 Cookie、CSRF 和 `{ "authorized": true, "mediaType": "audio/wav", "dataBase64": "..." }`。音频不超过 2 MB。返回 `{ "status": "review_required", "text": "..." }`，**只填草稿，不会直接向客服发送、推进护理或记录完成**。用户核对后手动点击发送。
- TTS：用户点击“朗读当前步骤”或“朗读这条回复”，`POST /api/customer/speech/synthesize` 需 Cookie、CSRF，与 `{ "authorized": true, "routineId": "当前流程ID" }` 或 `{ "authorized": true, "messageId": "本人客服回复ID" }`；**不接受浏览器提交任意合成文字**，后端读取当前步骤或本人已保存的可朗读回复（最多500字）调用豆包语音 HTTP 单向流式合成，返回短 MP3 给页面播放，不持久化。不可用时仍显示原文。点击录音会停止当前朗读，避免自播语音被识别为指令。

这些是两种不同火山接口：方舟图片/音频理解用方舟 Key 和模型 ID；豆包语音合成用语音 Key 和音色 ID。**尚未接豆包语音产品专用 ASR/持续监听**，这轮使用方舟音频理解转写短句。拿到具体账号后先核对模型权限、支持的音频格式和费用，再用自有授权样本验证：清晰/模糊/相似瓶/库外图；普通话、方言、噪声、“好了”误识、空音频；音色、播放停止和故障退回文字。识别失败、配额或余额不足不得触发完成事件。

运营端护理记录旁的 `GET /api/ops/modality-events` 记录本人用户 ID、图片/ASR/TTS 服务商、调用时间、成功/失败及受控错误码；**不保存原始媒体或识别文字**。仅用模拟响应的本地测试也会写测试记录，但那不等于实测证据。`GET /api/customer/video-moments` 可列出本机另行保存的“悦见时刻”素材批次，`DELETE /api/customer/video-moments/:jobId` 允许本人删除整批文件及清单；**没有视频生成服务**。
