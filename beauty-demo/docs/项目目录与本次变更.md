# 项目目录与本次变更

本文是仓库导航和本次提交说明。应用主体位于仓库的 `beauty-demo/` 子目录。

## 前后端与业务资料位置

| 内容 | 目录/文件 | 用途 |
| --- | --- | --- |
| 后端入口与 HTTP 路由 | `server/index.ts`、`server/app.ts` | 启动 Express 服务并挂载用户端、运营端和 Harness API |
| 客服编排、Jev/回复模型 | `server/core/` | 意图路由、Skill执行、模型适配、面部区域映射和安全规则 |
| 数据库与执行记录 | `server/storage/` | SQLite 用户/会话、消息、路由结果、Skill快照、人工队列和反馈 |
| 用户客服前端 | `web/customer/` | 聊天、会话历史、偏好资料、商品卡、面部区域图示 |
| 运营前端 | `web/operator/` | 模型配置、Skill上传/启停、运行记录和业务看板 |
| 双端共享样式 | `web/shared/styles.css` | 用户端与运营端共用视觉样式 |
| Skill源包 | `skill-packages/<skill-id>/` | 每个Skill的 `SKILL.md`、`manifest.json` 和可选 `references/` |
| 业务路由与提示 | `config/business.demo.json` | 演示意图、风险规则、技能描述及服务模板 |
| 产品/评论演示资料 | `content/templates/` | 明确标为演示的数据，不代表真实品牌资料 |
| 测试 | `tests/` | 单元、工作流、API权限及浏览器验收 |
| 文档和脚本 | `docs/`、`scripts/` | 项目说明、调研边界、导入/同步/诊断工具 |

目前仓库内的主要Skill包：

- `skill-packages/face-area-visual-guide/`：卧蚕/眼周、额头、脸颊、鼻部、下巴、T区、法令纹、易起皮和全脸常见范围的图示规则。
- `skill-packages/makeup-color-synesthesia-skill/`：面向熟龄用户的通俗彩妆与护肤解释，并带有语言研究和服务契约参考。
- `skill-packages/skincare-moment-video/`：约15秒护肤记录视频的素材授权、处理边界与服务契约；实际视频生成仍需配置视频服务。

## 本次修改

1. 增加 `face-area-visual-guide` Skill及区域视觉契约；以受控SVG人像绘制区域覆盖层，不上传或推断用户自拍。区域图跟随本轮问题或回复明确提到的部位；包含过敏/刺激语境时只显示位置说明，并提示不要据图继续涂抹。
2. Jev仅发生网络超时/断连时允许保守本地路由接管并继续调用已配置的回复模型。可能过敏或刺激的咨询走谨慎澄清，不做确定性诊断或商品推荐；高风险规则仍优先。Jev失败会保留在运营执行记录中，不伪装为Jev成功。
3. 修正用户端历史消息错误：曾把任意非空warning（包括成功兜底的warning）当成失败，导致覆盖已保存回答并隐藏图示。现在仅 `degraded`、`cancelled`、`interrupted` 终态显示通用失败文案。
4. 更新客服端会话历史、资料反馈和面部图示呈现，并更新运营端相关运行状态呈现；同步刷新 `config/business.demo.json` 与熟龄导购Skill说明。
5. 增加面部区域调研边界文档、演示资料同步脚本及演示图片资产；测试覆盖路由降级、历史消息序列化、区域图层和安全提示。
