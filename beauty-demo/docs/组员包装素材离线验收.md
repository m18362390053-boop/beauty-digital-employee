# 组员包装素材：离线接口验收（2026-10-14）

本机目录 `../material_from_groupmember` 有两组各 4 张 JPG（正面、背标、暗光、泵头），没有录音/视频样本。图片均能由本机解码；尺寸 SKU-01 正面/背标/泵头为 1080×1919、暗光为 810×1440；SKU-02 四张均为 1279×1706。每张小于 1 MB，未检测到 EXIF/GPS 标签。资料卡说明为团队自购实物拍摄、限比赛演示；**离线测试没有外发或留存原图**；此后另经用户明确同意，仅外发过一张 SKU-01 正面照，详见文末。

`tests/product-vision.test.ts` 的本地用例逐一读入这 8 张实际 JPG，验证图片编码/类型、方舟请求结构、未授权时拒绝、模型输出仅给待确认候选。外部请求由**测试替身**接收（不是火山模型识图），故本测试**不评估**这八张图的文字识别率、SKU 区分或实物验收。即使替身强行返回 SKU-02 的完整名字，隔离数据库未导入对应商品时，仍不得生成候选或完成事件。资料仍以原卡审核状态为准：SKU-01 草稿；SKU-02 仅有限可答字段；两者均没有正式护理计划，不自动入主库。

后续若要实测方舟图片识别，须先确认向火山外发这批团队照片的授权、使用额度和账户模型权限。在隔离演示库按正面/背标/暗光/泵头逐项记录模型真实返回和人工核对结论；不要把“文件名标签”当模型真值。还需补同系列不同版本及库外包装的授权样本。转写需组员提供真实录音（或明确同意使用合成语音作**合成样本**），并单独测试方言/噪音/空音频。当前没有实测录音或语音合成结果。

首次实测：用户明确同意外发最多两张正面照后，SKU-01 正面照的一次实际方舟请求返回 HTTP 404；当时立即停止，SKU-02 **在第一次实测时未发送**。本次没有识图结果，模型/账户设置仍需排查；详细配置状态见[火山多模态接入](火山多模态接入.md)。

用户随后明确要求再测，已将剩余额度用于 **SKU-02 正面照一次**，同一候选模型仍返回 HTTP 404，安全白名单内的供应商错误码为空。两次都没有产生图片识别结果，也未写入商品库；本次授权的两张照片已用尽，不再重发图片。`providerCode: null` 只能表示供应商错误响应不含已识别的白名单码（也可能不是预期的 JSON 结构），**不能**据此确定不存在供应商错误。需要账号方提供密钥用途类型与该账号控制台实际开通的模型 ID；不要在聊天中贴密钥。
