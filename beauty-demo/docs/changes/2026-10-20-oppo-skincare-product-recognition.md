# OPPO 护肤品识别：顾客端竖屏适配

**分支：** `feature/oppo-skincare-product-recognition`

## 更改记录

- 以 `feature/skincare-home-capture-consolidation` 为基线，保留已有的护肤品正反面拍摄/选图、OCR 候选、人工核对和共享日程流程；不改 Jev、运营后台或识别接口。
- 将顾客端首页三颗凝珠、咨询区、护肤日程中的商品录入区域调整为手机竖屏布局。手机上优先显示对话与输入框，咨询记录移到其后；保留原有配色和桌面布局。
- 修复商品时间轴已创建却没有加入页面的遗漏，使竖屏商品卡仍能显示开封至建议截止日的可视化轨道。
- 在本地 HTTP 或自签名 HTTPS 预览中，浏览器不提供 `crypto.randomUUID()` 时改用安全随机数生成 UUID v4，避免手机端保存护肤品或发送咨询时直接报错。
- 将已有数据库升级测试中的旧版本号断言更新为当前 schema v7；这是从基线发现的测试不一致，不改变迁移代码。

## 使用与边界

手机进入顾客端“护肤日程”，通过“拍摄正面/背面标签”或从相册选图，再点击“识别两面包装”。本机 OCR 由运行服务的 macOS 提供；外部视觉模型必须先配置，并由顾客单独勾选同意。识别结果仅是待核对候选，不会自动确认为商品。

本次只提交顾客端布局及其必需的兼容修复。局域网连接与公网访问问题不属于本分支；真实 OPPO 拍照、权限和端到端识别效果仍需在手机上验收。
