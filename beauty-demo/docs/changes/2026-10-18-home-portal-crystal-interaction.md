# 首页三颗凝珠交互反馈

**分支：** `feature/home-portal-crystal-interaction`  
**范围：** 仅顾客首页的三个入口凝珠，不涉及客服路由、业务逻辑、服务端或多 skill 命中基建。

## 变更说明

- 鼠标悬停、键盘聚焦和点击选中时，凝珠提亮并降低金色饱和度，呈现接近白色晶体的光泽。
- 按钮文字保持黑色，避免高光影响文字辨认。
- 键盘焦点提示放在凝珠自身光效中，不显示矩形方框。
- 页面底色、首页布局和三个入口功能保持原样。

实现位置：`web/customer/motion/home-portal.css`。本分支在现有交互样式上补充维护说明，没有更改路由或其他基础设施。

## 验证

- 本地客服预览中以键盘 Tab 聚焦“查看护肤日程”，确认凝珠内发亮、无方框焦点，黑色文字清晰。
- `npm run build` 和 `git diff --check` 通过。
