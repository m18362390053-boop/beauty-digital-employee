# 可选 USB 设备原型

本目录包含 Seeed XIAO ESP32S3 Sense 的**独立候选固件**：`xiao-esp32s3-usb/` 只取护理状态/重说，`xiao-esp32s3-media/` 用于独立图片和音频采集试验，`xiao-esp32s3-lcd-v3/` 只绘制 v3 状态。三份固件**不能同时烧录或当作已整合的整机固件**；分别与 `scripts/` 下的对应电脑工具配对。USB v3 消息契约见 [协议](../docs/ESP32S3-统一USB协议v3.md)。

本仓库交付的是网页体验与设备对接原型，**没有完成 LCD、触摸、摄像头、麦克风和喇叭在同一份固件上的实板闭环验证**。LCD 候选代码中的 ST7789 初始化/引脚是假设值，不是经核验的接线图；烧录前必须依据实际模块核对电平、供电、控制器、背光极性和引脚冲突。电脑保存设备 token 和模型凭据，固件不得包含这些私密信息；外部提交图片/录音前需本次明确同意。不使用 Wi‑Fi。
