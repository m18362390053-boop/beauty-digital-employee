# 可替换提供商接口

本文件定义能力边界，不代表阿里云、豆包或其他供应商已经接入。实施时按当前官方文档选择 SDK／鉴权方式；密钥只放环境变量或密钥管理服务，不写入仓库、日志或提示词。

## 标准输入

```json
{
  "image": "用户明确提供的本地图像或授权 URL，可为空",
  "product": {"brand": null, "line": null, "sku": null, "shade_code": null},
  "user_preferences": {"language": "zh-CN", "voice_speed": "normal", "desired_effect": null},
  "task": "identify_product_or_describe_color"
}
```

## 能力接口

| 接口 | 输入 | 输出 | 失败时 |
| --- | --- | --- | --- |
| `ProductCatalog.lookup` | 品牌、系列、SKU／条码、色号 | 官方名称、色卡、成分／质地、来源 URL、版本日期 | `not_found`；不得猜色号 |
| `VisionProvider.analyze` | 图像、目标区域，可选已匹配 SKU | 目标区域、OCR、色彩样本、光照／滤镜疑虑、置信度 | `not_configured` 或 `low_confidence`；建议补拍 |
| `ColorInterpreter.describe` | 可信色卡或图像样本、产品类型、用户偏好 | 明暗／冷暖／饱和度／质地、通俗类比、条件性建议、依据 | 缺关键资料时只描述可核验特征 |
| `SpeechProvider.synthesize` | 口播文本、语言、语速、音色偏好 | 音频 bytes、MIME 类型、时长 | 返回口播文本与 `not_configured`，不生成假音频 |

## 判定规则

- 不能只用 HSV 的色相角断定化妆品的「冷暖」：红、粉、棕的底色、明度、饱和度和实物光谱都会影响人眼判断。OpenCV 可用于取样、区域分割、色差与光照质量检测；语义色名需由人工校准过的品牌色卡映射或明确标注为估计。
- 色弱补偿不等于更长的形容词。至少输出一个相对参照（比同系列某色更偏橘／更深）、一个自然光复核动作、一个不确定性说明。
- 图库匹配与图像模型必须可替换。可以为阿里云、豆包、千问等分别实现适配器；不得在核心描述逻辑里写死任一提供商。
- 不推断年龄、健康状况或残障身份；用户自己选择无障碍模式、口播速度与详细程度。
- 评估至少覆盖：SKU 识别准确率、冷暖／明暗描述的一致性、低置信度拒答率、用户能否根据描述区分两支相近色、音频可理解度；邀请 45+ 与色觉差异用户分别共创和测试。
